# 변경 이력과 출처

## 2026-10-20 · 학습 문서와 재시작 절차

- 프로젝트 소개·구축·검증·증거·트러블슈팅 문서의 역할을 정리하고, 변경 내역은 이 문서에 모았습니다.
- 기존 교육·복습 노트에 명령 순서·설계 이유·용어 설명을 보강했습니다. GUI와 CLI를 섞은 검증·다섯 장애 시나리오 실습서는 별도 문서로 연결했습니다.
- 종료한 환경을 RDS/EBS 스냅샷과 기존 ECR/S3 자료로 재구축하는 `Resume-Project.ps1`을 추가했습니다. RDS snapshot 입력·Grafana 기존 PVC 선택 옵션과 해당 회귀 검사를 포함합니다.

- 재구축 중 발견한 ALB admission webhook과 ESO의 설치 순서 경합을 의존 관계로 보완했습니다. 실제 원인·조치는 TROUBLESHOOTING에 기록합니다.
